# Model sources

Replacements for the stock Half-Life gib and bone models, written by tools/model_art.py. Every shape is built in code; ambientCG materials are CC0 (https://ambientcg.com), and "drawn" skins are generated by the script.

| model | skins |
|---|---|
| `rockgibs.mdl` | `rock.bmp`: ambientCG Rock035 (CC0) |
| `woodgibs.mdl` | `wood.bmp`: ambientCG Wood049 (CC0) |
| `metalplategibs.mdl` | `metal2.bmp`: ambientCG Metal024 (CC0); `metal1.bmp`: ambientCG MetalPlates013 (CC0) |
| `glassgibs.mdl` | `glass.bmp`: drawn |
| `cindergibs.mdl` | `brokencinder.bmp`: ambientCG Concrete031 (CC0); `cinder.bmp`: ambientCG Concrete034 (CC0) |
| `fleshgibs.mdl` | `flesh.bmp`: drawn |
| `bonegibs.mdl` | `bone.bmp`: drawn |
| `bone.mdl` | `bone.bmp`: drawn |
